# Mechanical Design – CATIA V5

A collection of mechanical components and 3D models designed using **CATIA V5**. This repository showcases CAD modeling skills, feature-based design techniques, and engineering design practices for academic and personal learning.

## Overview

This repository contains various CATIA V5 part models created to improve proficiency in mechanical design and parametric modeling. Each model is developed by following standard CAD design methodologies and engineering drawing principles.

## Software Used

- CATIA V5
- Part Design Workbench
- Sketcher Workbench

## Repository Contents

- Mechanical Part Models (`.CATPart`)
- Assembly Files (`.CATProduct`) *(if available)*
- Engineering Drawings *(if available)*
- Reference Images/Screenshots

## Skills Demonstrated

- 2D Sketching
- Parametric Modeling
- Pad & Pocket Operations
- Shaft & Groove Features
- Hole and Thread Design
- Rib & Slot Features
- Boolean Operations
- Pattern & Mirror Features
- Assembly Basics
- Engineering Design Principles
